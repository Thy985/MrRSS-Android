# MrRSS Android

MrRSS Android 现在可以独立使用：手机直接抓取 RSS / Atom 订阅；文章正文、摘要、收藏、稍后读和阅读状态都保存在本机。若订阅只给摘要，可在文章详情中点“从原站提取全文（阅读模式）”，由阅读器在设备上抓取并整理原网页正文。无需先安装、启动或连接 MrRSS 服务端。

MrRSS 服务端是可选的。连接后，应用可以导入服务端的订阅和文章、将本机订阅推送到服务端，并同步已读、收藏和稍后读状态；服务端已有的文章还可以使用其配置的 AI 摘要和标题翻译。也可以在手机“设置”页独立配置兼容 OpenAI Chat Completions 的 AI 服务（接口地址、模型和可选 API 密钥），不连接 MrRSS 服务端也能翻译文章标题、总结文章正文、根据订阅及阅读/收藏线索推荐未读文章，或围绕当前文章提问。问答优先使用成功提取的原站全文并引用编号段落；若未能提取全文，则明确只根据现有摘要回答。API 密钥通过 Android Keystore 加密保存在本机；进行 AI 操作时，相关标题、摘要、正文、问题或推荐所需的订阅与阅读线索会发送到所配置的服务，请只填写可信服务地址。断开服务端不会删除本机数据。原站全文提取需要网络，受登录墙、反爬限制及 JavaScript 渲染页面影响；失败时可点“在浏览器打开原文”。提取成功后正文缓存在本机，可离线阅读。

## 使用方式

在“订阅”页添加 RSS 或 Atom 地址，例如 `https://example.com/feed.xml`。应用会尝试立即获取内容；之后点文章页右上角的刷新按钮即可直接更新本地订阅。文章和阅读状态通过本机 SQLite 数据库保存。

也可以在“订阅”页点“导入 OPML”从设备选择 `.opml` 或 XML 文件；支持嵌套分类，重复或非 HTTP(S) 地址会跳过。点订阅条目右侧的菜单可修改名称、地址和分类，或删除订阅及本机已保存的文章。连接服务器时编辑和删除会同步到服务器；离线删除会在下次连接后同步。

如需服务器同步，在“设置”页填写可由手机访问的 MrRSS 服务地址并选择“连接并同步”。若使用手机端 AI，在同一页面的“可选 AI 服务”卡片填写兼容接口地址和 API 密钥；点“获取模型”可从兼容的 `/models` 接口读取模型并选择，也可继续手动填写模型 ID。点“测试连接”会向所选模型发送一条极短的 Chat Completions 请求，服务商可能计费；获取模型只读取模型列表。配置后，文章列表中的“为我推荐”会根据订阅、已读文章、收藏和稍后读记录推荐未读候选；推荐历史及理由会保存在本机，后续推荐自动跳过已推荐过的文章，仅增量展示新文章。点选结果会在应用内打开。文章详情提供“问这篇”入口；若回答只基于摘要，界面会明确提示。文章详情中的“AI 总结”和“翻译标题”也可直接对本机文章使用；目标语言在“翻译”卡片中设置。服务器添加订阅与文章刷新遵循服务端 API 行为；刷新可能在后台继续完成。若没有配置手机端 AI，仍可使用已连接 MrRSS 服务端提供的 AI，但仅限同步到服务端且具有远端文章 ID 的摘要和标题翻译。

## 构建 APK

用 Android Studio 打开 `android/` 目录，安装 Android SDK 35，并同步 Gradle 项目。选择 **Build > Build APK(s)**，生成的调试 APK 位于 `app/build/outputs/apk/debug/`。也可以运行：

```sh
./gradlew assembleDebug
```

应用最低支持 Android 8.0（API 26）。

## 安全说明

RSS 内容由 Android 客户端直接从订阅源请求；为兼容可信自托管源，应用允许 HTTP。优先使用 HTTPS，尤其不要在不受信任的网络中传送敏感内容。

MrRSS 服务端当前没有内置用户登录或访问控制。若选择连接服务端，请仅在可信局域网内使用，或通过带身份验证的 HTTPS 反向代理 / VPN 访问；不要直接暴露到公网。应用不支持多个本机账户或通知推送。项目采用 GPL-3.0，与 MrRSS 主仓库许可保持一致。
